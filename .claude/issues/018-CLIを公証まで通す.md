# 018 CLI を公証まで通す（2026-09-12・実測で分かった）

## 何が起きるか（**実測**）

`v0.1.4` の CLI は **Developer ID で署名されている**（`flags=0x10000(runtime)` /
`TeamIdentifier=SNZK24Z6S4` / `codesign --verify --strict` 通過）。
**それでも、ブラウザで落とすと動かない。**

| 試したこと | 結果 |
|---|---|
| 隔離属性なしで `warifu version` | **`warifu 0.1.4`**（動く） |
| **隔離属性つき**で同じ実行ファイル | **出力なしで固まり、しかもファイルが消えた**（2 回再現） |

```bash
# 再現の仕方
cp warifu warifu-q
xattr -w com.apple.quarantine "0081;68c3a000;Safari;$(uuidgen)" warifu-q
chmod +x warifu-q
./warifu-q version     # 固まる。そのあと ls すると消えている
```

**署名だけでは足りない。**macOS は Developer ID で署名されたコードに**公証**を要求する。
**単体の実行ファイルに公証の券は貼れない**（券はアプリの束か `.dmg` に貼る・**D101**）。

**黙って消えるのが特に悪い。**落とした人には「ダウンロードが失敗した」としか見えない。

## 当面の逃げ道（案内に書く）

```bash
xattr -d com.apple.quarantine ./warifu
```

**先に外してから、初めて実行する。**実行してから外そうとすると、もう消えている。

## 直し方（案・**まだ決めていない**）

| 案 | 中身 | 良い所 / 悪い所 |
|---|---|---|
| **A. `.pkg` にする** | CLI を `.pkg` に包み、`productsign` ＋ 公証 ＋ **券を貼る** | **券が貼れる**＝網が無くても通る。`/usr/local/bin` へ入るので PATH の案内が要らない。／ 入れ物が増える |
| B. `.zip` で公証する | `notarytool submit warifu.zip` | 手間が小さい。／ **券を貼れない**ので、Gatekeeper がその都度**網で問い合わせる**。社内網で外へ出られないと止まる |
| C. いまのまま ＋ 案内 | `xattr` を案内に書く | 費用ゼロ。／ **人に毎回おまじないを打たせる**。「消えた」を踏む人が出る |

## 決めたこと（2026-09-12・**B を採った**）

**A（`.pkg`）は今すぐ選べない** —— `productsign` には **Developer ID *Installer* 証明書**が
別に要る。いまの secrets にあるのは `.app` を署名している **Application 証明書だけ**である。
**証明書の用意は人の判断と費用**（baseline §14 / §29）。

**B（zip を公証に出す）を `release.yml` に入れた。**いまある
`APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` でできる。

```yaml
ditto -c -k target/release/warifu "$RUNNER_TEMP/warifu-cli.zip"
xcrun notarytool submit … --wait --timeout 30m | tee /tmp/cli-notary.txt
grep -q 'status: Accepted' /tmp/cli-notary.txt || exit 1
```

- **待つ**（`--wait`）。出しただけで先へ進むと、通ったか分からないまま配る
- **`status: Accepted` を確かめる。**握り潰さない
- `ditto` に `--keepParent` を付けない（単体のファイルだと親フォルダ名まで包みに入る。手元で確かめた）

**券は貼れないままである** —— Gatekeeper が**初回にオンラインで問い合わせる**形になる。
**外へ出られない機械では、まだ `xattr` が要る。**そこを直すには A が要る。

### **効くのは次の版から。**`v0.1.4` の CLI には公証が無い（`xattr` が要る）

**案内は測ってから書き換える** —— `v0.1.5` を出して、
**隔離属性を付けた実物が動くことを確かめてから**「`xattr` は要りません」と書く。
`v0.1.3` で「署名しました」と書いて**実際は adhoc だった**のと同じ形を、3 度やらない。

## 残っている宿題

- **A（`.pkg` ＋ 券）** —— Installer 証明書が取れたら。**外へ出られない機械のため**
- Windows の署名（証明書が無い。同じく人の判断と費用）

## 止めるべき条件

- **CLI を配らない形にするなら、この Issue ごと不要**（画面だけで足りるなら）
