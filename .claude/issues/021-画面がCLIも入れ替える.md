# 021 画面が CLI も入れ替える（**オーナー承認済み・未着手**）

**2026-09-24、オーナーが案 A を選んだ**（「**AdeOK.**」）。
**そのあと文脈が切れて、計画そのものが残っていなかった** ——
**承認だけが残って、何を作るかが消える**のは、いちばん悪い落とし方である。**だから先に書く。**

## いま何が起きているか

```
画面   自動更新で上がる（Tauri の updater・latest.json）
CLI    **上がらない。**別の実行ファイルで、人が手で入れ替える
```

**`.claude/issues/017`【1】で、Mac Air の席がこう指摘している** ——

> 案内は「アプリを終了して開き直すと更新の案内が出ます」でしたが、CLI（`~/.local/bin/warifu`）は
> 別バイナリで、そのままだと 0.1.2 のまま残ります。**アプリだけ上げた人は
> 直ったつもりで直っていません。**しかも症状は「繋がらない」だけなので、
> **CLI が古いせいだと気づけません。**

**2026-09-12 に「古いときだけ言う」までは入れた**（`cli.rs` ／ `lib/update/cli.ts`）。
**言うだけである。**——**入れ替えるのは、いまも人の手**である。

## 決めたこと（**案 A**・オーナー承認 2026-09-24）

**画面が CLI も入れ替える。**

## どう作るか（**こちらの推し。違ったら止めてほしい**）

**CLI を `.app` の中に同梱して、画面がそれを置く。**

```
いま      画面を上げる → 人が別途 CLI を落として置く
これから  画面を上げる → **束の中の CLI を、画面が置く**（網に出ない）
```

| なぜこの形か | |
|---|---|
| **網に出ない** | 落とす経路を新しく作らない。**署名も公証も、束と一緒に済んでいる** |
| **版がずれない** | 同梱なので、**画面と CLI が必ず同じ版**になる（issues/017【1】の芯） |
| **失敗の形が読める** | 置けなければ「置けませんでした」と言える（落とす途中で切れる形が無い） |

**落とし穴 5 を踏まないこと** ——
**`cp` で上書きすると macOS が署名を覚えているので `Killed: 9` で黙って死ぬ。**
**`rm -f` してから置く。**

### 決めていないこと（**人に聞く所**）

```
① **黙って置くか、押させるか**
   PATH の中の実行ファイルを、黙って差し替えるのは強い。
   **こちらの推しは「1 回押させる」** —— 帯に「CLI も上げますか」を出す。
   **既定で黙って置くのは、baseline §13（破壊的な操作は人へ確認）に触る**
② **どこへ置くか**
   いまの `cli.rs` は `~/.local/bin` → `/usr/local/bin` → `/opt/homebrew/bin` の順に探す。
   **見つかった所に置く**（新しい場所を勝手に作らない）。
   **どこにも無い人には何もしない**（入れていない人に警告を出さないのと同じ筋）
③ **Windows**
   `warifu.exe`。置き場所が違う（`%LOCALAPPDATA%`）。**macOS と同じ手が使えない**
```

## 段

```
段 1  CLI を束へ同梱する（tauri.conf.json の resources）
      **CI の段の順番に注意**（落とし穴 3）—— CLI を建てる段が、束を作る段より先に来ること
      いまの release.yml は「CLI を建てる」が「配布物を作る」より先にある（段 86 → 199）
段 2  画面が束の中の CLI の版を読む（いまの `cli_state` の隣）
段 3  **押したら置く**（`rm -f` してから）。置けたら版をもう一度読んで、揃ったことを見せる
段 4  Windows は別に決める
```

## やらないこと

- **網から CLI を落とす** —— 経路が増え、署名の検めも自分で書くことになる
- **黙って差し替える** —— PATH の中の物を、断りなく置き換えない
- **CLI を画面と 1 つの実行ファイルにする** —— CLI は画面が無くても動くことが値である

## 確かめ方（**人が押す所**）

```
1  古い CLI を置いた機械で、新しい画面を開く → **帯に「CLI も上げますか」が出る**
2  押す → 置き換わる。**`warifu --version` が画面と同じ版になる**
3  **入れていない機械では、帯が出ない**（消せない警告を作らない）
4  置けない機械（権限が無い所）では「**置けませんでした**」と場所を名指しで言う
```
