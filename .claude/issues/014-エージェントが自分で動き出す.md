## どこから来たか

2026-09-07。**実物で詰まったところから出た。**

机（**D55**）で人と AI が同じ会話に着けるようになった。往復も通った。
だが**オーナーが打っても、私（AI）は気づかなかった。**

> **返事に気づけてないけど、どうする？**

## 何が起きているか

**MCP は「呼びに行く」形である。**`chat_read` を叩いたときしか見えない。

```
AI → 画面   即時（画面が出来事を受けている）
画面 → AI   **AI が chat_read を叩いたときだけ**
```

**片側だけ即時である。**

そして **MCP サーバから Claude Code の会話に割り込む口が無い。**
届いたことを知らせても、エージェントの手番は来ない。

## なぜこれが要るか（**営業のシナリオがここで止まる**）

オーナーが出した筋（2026-09-07）——

> 営業が外で、LINE で顧客の依頼をうける。それを割符をとおして、
> **PC のエージェントをよんで、対応させる。**そしておわったら
> **PC のエージェントが営業に割符を通して終わったと連絡をいれる。**

**「呼んで、対応させる」も「終わったと連絡をいれる」も、
エージェントが人に声をかけられずに動くことを要求している。**

いまのエージェントは、**人が Claude Code で何か言うまで動かない。**

## いま埋められること（作らずに）

| | やり方 | 限界 |
|---|---|---|
| 人が声をかける | 「読んで」と言う | 人が居ないと動かない |
| `/loop` | Claude Code の繰り返しで `chat_read` を叩く | 手番を消費する。間隔ぶん遅れる |

## 考えられる形（**決めていない**）

### ① `chat_read` を待ち受け型にする（小さい）

空のときにすぐ返さず、**来るまで最大 N 秒待つ。**
`/loop` の間隔を空けても取りこぼさなくなる。

**限界** —— エージェントの手番の中でしか待てない。**手番の外では動かない。**

### ② 常駐する側を作る（本命）

`warifu agent` のような**机に着いて待つプロセス**を置く。
届いたら、決められた仕事を回す。

**決めること** ——
- **何を回すか。**モデルを呼ぶのか、手順を回すだけか
- **札は誰が出すか。**常駐が勝手に動く以上、**何をしてよいかは前もって決めておく必要がある**（関所・D5）
- **人が居ない間に動いたことを、どう人へ見せるか**（後から追える形）
- **暴走をどこで止めるか**

### ③ Claude Code を外から叩く

いまの Claude Code に、外から手番を渡す口は無い。
**あるかどうかから調べる話。**

## 止めるべき条件

- **常駐が、人の確認なしに外へ出す形になったら止める。**
  「commit は AI、push は人間」（baseline §6）と同じ線を、ここにも引く
- **札を常駐が自分で出せる形にしたら止める**（baseline §14 / D25）

## 実行状況

**実装していない。**①〜③ のどれを採るかがオーナー判断。

## 2026-09-08 追記 —— **① を入れた**（`chat_wait` / **D65**）

オーナー提案 ——「**この投稿に気づく件は MCP とかにリストされているほうが、
使おうと AI も思いませんかね？**」

**そのとおりだった。**「待つ」という選択肢が道具の一覧に無かったので、
エージェントは待つことを考えもしなかった。

`chat_wait` を**独立した口として並べた**（`chat_read` の隠し引数にしない）。

| | |
|---|---|
| **埋まった** | エージェントが**自分の手番の中で**待てる |
| **埋まらない** | **手番の外では動かない。**呼ばれていないエージェントは待ちに行かない |

**この Issue の本題（② 常駐する側）は残っている。**


---

## 2026-09-08 追記 —— **② が入った**（`warifu agent` / **D67**）

```
warifu agent --on <命令>
```

机に着いて待ち、**届いたら人が決めた命令を起こす。**
命令の言ったことを、そのまま会話へ流す。

**実物で確かめた**（12:59）——

```
私が話す      もう一度。呼ばれずに答えられますか。
zumen の AI   受け取りました: もう一度。呼ばれずに答えられますか。
```

**誰も zumen を呼んでいない。**

### いちばん大事な決めごと

**届いた文字を、命令にしない。**標準入力へ渡すだけで、引数にも環境変数にも入れない。
入れると「`rm -rf ~` と書いた文字を送るだけで消える」ことになる。

### まだ無いもの（この Issue はまだ閉じない）

- **人が居ない間に動いたことを、画面から見る口**（いまは常駐の標準エラーだけ）
- **止める口**（いまは常駐を落とすしかない）
- **何度も動かない仕掛け**（同じ文字が 2 回届けば 2 回動く）
