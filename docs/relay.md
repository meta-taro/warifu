# 預かり所を立てる（`warifu relay`）

> **これは「割符が用意する中央」ではありません。**立てるのは、導入した人です（`.claude/decisions.md` **D68** / **D71**）。
> 立てなくても割符は動きます。**相手が起動している間だけ**届く、という形になります。

---

## 何のためにあるか

割符はサーバーを 1 台も立てないので、**相手が起動していなければ、送った言葉は消えます。**

```
   A ──封──▶ 預かり所（中身は読めない）
                  │
   B が起動 ──────┘ 受け取って、預かり所からは消える
```

預かり所は**封のまま**持ちます。開ける鍵を持っていないので、**読めません**（**D69**）。

| | |
|---|---|
| 預かる日数 | **7 日**。過ぎたら捨てます |
| 1 人あたり | **200 通**まで。**1 人が埋めても、他の人が使えなくなりません** |
| 1 通 | **64 KB** まで |
| 渡したら | **手放します。**溜め込む場所にしません |

---

## 1. 使ってよい人を書く（**人が書きます**）

**公開鍵を 1 行ずつ。**`#` から始まる行は注記です。

```text
# 開発の 3 人
KKD7IOAKQBSUE6LOTX3HYKFZI7OEEVIWZYI3RK5ZVNOP4MT4ZTXA
SSYWJBFMA2ASFD4TJOHZWM2OQ6GRSU2E5NQSDU35YPACENJLKBOA
```

公開鍵は、その人の手元で `warifu id` が出します。**秘密の値ではありません**（配って構いません）。

読めない行は**その行だけ**捨てます。**書き間違いで全員が通る／全員が締め出される、を避けるため**です。

---

## 2. 立てる

```bash
warifu relay --allow-file ~/warifu-allow.txt
```

```text
WARIFU1-K5JEMQIDGMPXZIZCTK4GJRUJXTWOWSTU…      ← 標準出力。これを配ります
warifu relay: 立ちました（使ってよい人 2 名）。上の宛先を配ってください。
預かるのは 7 日まで。中身は読めません。
```

**名簿が空なら起動しません。**

```text
warifu: 使ってよい人の一覧がありません。--allow-file <場所> に公開鍵を 1 行ずつ書いてください
```

これは不便のためではありません。**空で立つと、立てた人が知らない誰かの通信を運ぶ**ことになります。

---

## 3. 落ちても困らないように

- **預かっている封は、機械の中だけにあります**（閉じると消えます）。
  消えて困るものを置く場所ではありません。**7 日で捨てる**のと同じ考え方です
- 常に立てておきたいなら、`launchd` / `systemd` / タスクスケジューラに任せてください

---

## 気をつけること

- **名簿は人が書きます。**割符が自動で足しません（**D56** と同じ構え）
- **名簿に無い相手は、黙って落とします。**断る理由は返しません（**D31**）。手元の記録には残ります
- **預かり所は「誰が誰へ送ったか」を知りません。**封は使い捨ての鍵でされていて、差出人が入っていません
- **外へ出す機械に立てるなら**、それは「不特定の人の通信を運ぶ」に近づきます。
  国によっては届出が要ります。**うちうちで使う分には要りません**（**D68**）
