# 試験運用の手順（M5・2 人の会議）

> **これは AI が作りきった所までの引き渡しである。**
> ここから先は、実物を触った人にしか分からない（product-baseline §29）。
>
> **合否や気づいた点は、触った人が自分の言葉で書く。**
> AI に要約させない（§19 / §27）。要約した時点で、本当に困っていた所が落ちる。

## 0. 先に知っておいてほしいこと

| | |
|---|---|
| **閉じると別人になる** | 鍵を保存していない。起動のたびに新しい身元を作る。**不具合ではない** — `decisions.md` の **D2**（全端末を失ったときの復旧モデル）が未決で、決める前に「とりあえずファイルへ置く」をやると、それが既成事実になるため |
| **外部の STUN / TURN を使っていない** | 既定で他人のサーバへ自分の存在を知らせない。**同じ Wi-Fi / LAN なら繋がる。厳しい NAT を越えると繋がらない**（中継を入れるかは D3 / D7 が未決） |
| **招待は 10 分で切れる** | `招待を出す` を押すたびに、前の招待は無効になる。**一度に有効なのは 1 つ**（D39） |
| **QR はまだ無い** | 招待は文字列だけ。紙・口頭では運べる形になっている |
| **3 人以上はまだ** | 橋が持っている経路は 1 本 |
| **アイコン** | **割符**（二つに割った札）。手で書き起こしたもので、外部の権利関係は無い（`DESIGN.md` §4-A） |
| **最初は音声だけ** | 経路を測るまで映像を流さない（**D29**「測る前に映像を出さない」）。**映像が一拍遅れて出るのは仕様である。**遅すぎると感じたら、それは報告してほしい所 |

## 1. 動かす

2 台要る。**同じ Wi-Fi につないでおく。**

```bash
git clone https://github.com/meta-taro/warifu.git
cd warifu
scripts/setup-hooks.sh     # clone ごとに 1 回
pnpm install
pnpm --filter @warifu/desktop tauri dev
```

初回は依存を建てるので数分かかる。

> **`cargo run` では動かない**（2026-09-03 に踏んだ）。
> debug ビルドの Tauri は `devUrl`（`http://localhost:5173`）を読みに行くので、
> vite を一緒に起動しないと**窓が真っ白になる**。`tauri dev` が両方を面倒みる。
>
> 配布物として動かすなら `pnpm --filter @warifu/desktop tauri build`。

## 3. 特に判断してほしいこと

**AI では決められない所である。**

1. **経路バッジの出し方と、映像が出るまでの間** — `直接` / `中継` / `不明` の 3 つで足りるか。
   「直接」を名乗るまで 3 回待ち、**測れるまで映像を流さない**作りにしてある（D29）。
   **待たされている感じがするか。**ここは体感でしか判断できない
2. **招待の渡し方** — テキストの貼り付けで運用に耐えるか。QR が要るか、紙で足りるか。
   **10 分という有効期間は短すぎないか**（D39 の「覆してよい条件」）
3. **`閉じると別人になる`** — 試験の間これで我慢できるか、**D2 を先に決めるべきか**
4. **定員 12** — 実測前の文献値。2 人で使ってみて、**12 が現実的に見えるか**
5. **訳文**（en / zh / ko）— **AI の下書きのまま**である。直すか、言語を減らすか

## 6. 動かないときに見る所

| 症状 | 見る所 |
|---|---|
| **繋がらない** | 同じ Wi-Fi か。**外部 STUN を使っていない**ので、網が分かれていると繋がらない |
| **繋いでも何も起きない** | 招待が切れていないか（10 分）。**割符が合わない相手は黙って落とす**（D31・断る理由を返さない） |
| **映像が出ない／片方だけ出る** | offer を出すのは一方だけ（**D38**）。両方から出ていたら、それは不具合である |
| **経路バッジが `不明` のまま** | `RTCStatsReport` の形が想定と違う可能性がある。**`path.ts` は実機で一度も確かめていない** |
| **窓が真っ白** | まずフロントの build（`pnpm --filter @warifu/desktop build`）。**それでも白いなら CSP を疑う** — 2026-09-02 に、`script-src` を書き忘れて SvelteKit の起動スクリプトが止まり、真っ白になった実績がある |
