# 試験運用の手順（M5・2 人の会議）

> **これは AI が作りきった所までの引き渡しである。**
> ここから先は、実物を触った人にしか分からない（product-baseline §29）。
>
> **合否や気づいた点は、触った人が自分の言葉で書く。**
> AI に要約させない（§19 / §27）。要約した時点で、本当に困っていた所が落ちる。

---

## 0. 先に知っておいてほしいこと

| | |
|---|---|
| **閉じると別人になる** | 鍵を保存していない。起動のたびに新しい身元を作る。**不具合ではない** — `decisions.md` の **D2**（全端末を失ったときの復旧モデル）が未決で、決める前に「とりあえずファイルへ置く」をやると、それが既成事実になるため |
| **外部の STUN / TURN を使っていない** | 既定で他人のサーバへ自分の存在を知らせない。**同じ Wi-Fi / LAN なら繋がる。厳しい NAT を越えると繋がらない**（中継を入れるかは D3 / D7 が未決） |
| **招待の口がまだ無い** | 今できるのは「宛先を渡して繋ぐ」だけ。QR も紙も、まだ画面に出ない |
| **3 人以上はまだ** | 橋が持っている経路は 1 本 |
| **アイコンは仮** | 意匠を含まない角丸の四角。ロゴが決まったら捨てる |

## 1. 動かす

2 台要る。**同じ Wi-Fi につないでおく。**

```bash
git clone https://github.com/meta-taro/warifu.git
cd warifu
scripts/setup-hooks.sh     # clone ごとに 1 回
pnpm install
pnpm --filter @warifu/desktop build
cd apps/desktop/src-tauri && cargo run
```

初回の `cargo run` は依存を建てるので数分かかる。

## 2. 触る順番

| | やること | 見てほしい所 |
|---|---|---|
| 1 | 両方の窓を開く | **窓枠が自作のものになっているか**（OS の白い帯が出ていないか）。ダークとライトの両方で |
| 2 | 片方の「自分の宛先」をコピーする | 全桁が選べるか。**等幅で読めるか** |
| 3 | もう片方の「相手の宛先」へ貼り、`繋ぐ` | 名簿が `2 / 12` になるか |
| 4 | カメラの許可を出す | **断ったときの文言が、何をすればいいか分かる形か** |
| 5 | 映像が出るのを待つ | 何秒かかったか。**音は回り込んでいないか** |
| 6 | 相手のタイルの経路バッジを見る | `不明` → `直接` へ変わるか。**跳ねていないか**（ちらつき） |
| 7 | 片方の窓を閉じる | もう片方に「経路が閉じました」が出るか |
| 8 | 窓を狭くする | 860px を切ると縦に積む。**名簿が先に消えていないか** |
| 9 | 言語を切り替える（今は OS の言語で決まる） | 日本語以外の訳が読めるか。**特に「取り消せません」「断りました」** |

## 3. 特に判断してほしいこと

**AI では決められない所である。**

1. **経路バッジの出し方** — `直接` / `中継` / `不明` の 3 つで足りるか。
   「直接」を名乗るまで 3 回待つ作りにしてあるが、**待たされている感じがするか**
2. **宛先の渡し方** — テキストの貼り付けで運用に耐えるか。QR が要るか、紙で足りるか
3. **`閉じると別人になる`** — 試験の間これで我慢できるか、**D2 を先に決めるべきか**
4. **定員 12** — 実測前の文献値。2 人で使ってみて、**12 が現実的に見えるか**
5. **訳文**（en / zh / ko）— **AI の下書きのまま**である。直すか、言語を減らすか

## 6. 動かないときに見る所

| 症状 | 見る所 |
|---|---|
| **繋がらない** | 同じ Wi-Fi か。**外部 STUN を使っていない**ので、網が分かれていると繋がらない |
| **映像が出ない／片方だけ出る** | offer を出すのは一方だけ（**D38**）。両方から出ていたら、それは不具合である |
| **経路バッジが `不明` のまま** | `RTCStatsReport` の形が想定と違う可能性がある。**`path.ts` は実機で一度も確かめていない** |
| **窓が真っ白** | フロントの build を忘れていないか（`pnpm --filter @warifu/desktop build`） |
