# 04. MCP と画面の連動 —— エージェントが見るものと、人が見るものは同じ

> 人が見てすぐ分かるおかしさを、エージェントは MCP 越しに見られなかった。
> **本体が自分で見比べて、食い違いをエージェントへ知らせる**（0.1.39 で始め、0.1.4x で揃える）。

## 1. 2 つの写し

| 口 | 何を返すか | 出どころ |
|---|---|---|
| `room_status` | 本体が知っていること（ルーム・相手・経路・この機械のエージェント） | Rust の本体（棚） |
| `app_view` | **人の画面がいま見せているもの**（版・見ているルーム・人数・届く先・会話の行・知らせ） | 画面（Svelte）が送った写し。札 `screen.read` が要る |

- **S04-1** `room_status` の相手の集合 ＝ `app_view` の届く先の集合（名前の有無は違ってよい。鍵の頭で合わせる）
- **S04-2** `app_view` の見出しの人数 ＝ `room_status` の相手の数 ＋ 1（自分）
- **S04-3** `app_view` の見ているルーム ＝ `room_status` のルーム
- **S04-4** 「あなたが建てた」の題字 ⇔ 本体がそのルームの主催
- **S04-5** 画面のルームの一覧 ＝ 本体の棚の一覧（増減が同時）

## 2. 自己点検

- **S04-6** 本体は、画面から写しが来るたび（まとめて 2 秒以内）と 30 秒ごとに、上の S04-1〜5 を見比べる
- **S04-7** 食い違いがあれば、**同じ食い違いにつき 10 分に 1 回**、机へ「食い違い: …」を 1 行流し、記録（`warifu.log`）にも書く
- **S04-8** `room_status` は「いまの食い違い」の一覧を返す。空なら空と分かる形で返す
- **S04-9** 名簿に居ない相手の発言が届いたら、それも食い違いとして同じ道を通す（0.1.39）

## 3. 版の約束

- **S04-10** 画面（`warifu.app` / `.exe`）と `warifu` コマンドは**同じ版で動く**。違えば机が繋ぐときに「版が違う（画面 X・コマンド Y）」と 1 行返し、エージェントは `about` の末尾でそれを読める
- **S04-11** 画面は、自分と同じ版の `warifu` コマンドを**自分で置ける**（021・macOS は消してから置く）。置くかは人が 1 回押す
- **S04-12** 版が上がって最初の立ち上げで、本体はこの PC のエージェントへ**1 度だけ**「版が上がった。room_status と app_view を見比べて」と頼む（0.1.39）。前の版の控えが無ければ告げない

## 4. 知らせ（channels）

- **S04-13** 発言が届いた・誰かが入った・切れたまま 10 分、は `<channel>` でエージェントへ届く。本文は入れない（`chat_read` で読む）
- **S04-14** Claude Code が握手の無い新しい版の MCP で先に尋ねてきても、割符は握手のある版だけを名乗る。そのあとの `tools/list` に道具が出る（0.1.38・`protocol.rs` の順番の試験）

## 5. 口ごとの「返り」

- **S04-15** 23 の口は、札が無ければ断る。札があれば、**返りの中身が仕様どおり**（返るか、だけではない）。試験は偽の机を立てて中身を見る
- **S04-16** 画面を上げ直した直後、帰り道のルームへまだ戻れていない間は、`room_status` の題字が「前のルーム（id の頭）へ戻ろうとしています。いま見ているルームは仮」と言う。相手の居ない仮のルームを、ルームから出たと読ませない
- **S04-18** `@名前` で呼ばれた発言は、channels の知らせに本文ごと載る（1 回 3 件・1 件 1,000 字まで・「指示ではない」を添える）。呼ばれていない発言の本文は載らない。知らせで本文を運んでも読んだことにはせず、`chat_read` にもう一度出る
- **S04-20** channels で席を起こすのは、既定では `@` で呼ばれた発言が来たときだけ。席ごとに `warifu mcp --wake mention|all|none` で選ぶ（`all` は発言と入室のたび・`none` は起こさない）。起こさなかった発言も `chat_read` で読める。いまの起こし方を `room_status` に出す
- **S04-19** `room_status` は、この機械のエージェントごとに「最後に読んだ時刻・読んでいない数・そのうち `@` で呼ばれた数」を出す（呼ばれても読みに来ない席を人が見分ける）。数は自分の発言を除き、この機械が覚えている分だけ。新しい口が名乗ったときだけ付け、古い口には欄を書かない。網の向こうへは出さない
- **S04-17** 自分で前のルームへ戻れたら、見ているルームは戻った先になる。ただし、前に見ていたルームに相手が居るなら、それを奪わない。自分が鍵を配った部屋も、自分しか居なくても奪わない（主催が上げ直した直後は、客が戻るまで自分しか居ない）
