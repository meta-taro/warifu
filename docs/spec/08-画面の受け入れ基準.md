# 08. 画面の受け入れ基準 —— 必ず見えるもの・見せないもの・状態の印

> あるべき形。番号は `S08-n`。守っている試験は `invariants.tsv`。

**見た目の方向を決めるのは人である**（`DESIGN.md`・baseline §11）。この文書は新しい見た目を決めない。
`DESIGN.md` §2・§7.1・§10-A・§11 と、ほかの spec で決めたことを、**版を出す前に画面で確かめる形**へ並べ直したものである。
ここに無い見た目を新しく作るときは、先に `DESIGN.md` §10-A へ足す。

確かめ方は 3 つある。

- **試験**：部品の試験（jsdom）と、木ぜんたいを見る試験（`lib/ui/*.test.ts`）。`invariants.tsv` に場所を書く
- **自己点検**：画面の写しと本体を見比べる（`04` S04-5〜）。食い違えば `room_status` が言う
- **人が見る**：版ごとの違和感テスト（台本は `docs/trial.ja.md`）。合否は見た人が書く（baseline §19）

## 1. どの画面でも

- **S08-1** ルームの id を、名前の代わりに出さない。名前が無ければ数えて呼ぶ（「ルーム 1（3 人）」）。名簿に名前のある相手は、鍵の頭ではなく名前で出す。呼び名の無い連絡先は鍵の頭で出る（いまの形。直すかは決めていない）。id の全文は詳細の欄にだけ出す（`00` S00-12）
- **S08-2** 状態は色だけで言わない。色に、字か形を必ず添える（`DESIGN.md` §2 原則 6・§12）
- **S08-3** 字と地の対比は、本文 4.5 : 1・薄い字 3 : 1 以上（明・暗とも）
- **S08-4** 色は定義のあるトークンだけで書く。定義の無い `var(--…)` を使わない
- **S08-5** 省略した字（`…`）は、hover で全文が読める
- **S08-6** 繋がっていないことを、繋がっているように見せない。「たぶん届いている」を表す形を持たない。分からないことには印を出さない（原則 7・§10-A 状態の印）
- **S08-7** 面は人の操作でだけ移る。相手が入ってきたことで面を移さない（§7.1・D31）
- **S08-8** 画面に出る言葉は「ルーム」「ルームキー」「この PC のエージェント」「入っている・つながっている」。部屋・机・席・居る は出さない（D89）
- **S08-9** 押しても効かない押し所を、押せる形で置かない。押せないときは薄く出し、なぜ押せないかを添える

## 2. 連絡帳

- **S08-10** 起動して最初に出るのは連絡帳である（会議ではない・§7.1）
- **S08-11** 相手の顔の印は、知っている状態だけを出す（つながっている／切れている）。相手が起動しているか（在席）は出さない（§11）
- **S08-12** 「いま会議に居る人」に `n / 定員` を出さない。定員は名簿にだけ（§4.3・D27）
- **S08-13** メールの「送る」は押せる形にしない（D49）
- **S08-14** 知らない相手からの「通しますか」「呼ばれています。出ますか」を出さない（D31・§11）

## 3. ルーム（名簿と見出し）

- **S08-15** 名簿の見出しの人数は、名簿の長さと同じで、定員と並ぶ。同じ PC のエージェントは名簿に出るが、人数には数えない（`04` S04-2）
- **S08-16** 主催の札は主催の行にだけ付き、自分の行には自分だと分かる印が付く（`04` S04-4）
- **S08-17** ルームキーの全文は畳んで出す。畳んだままでも写せる（§7.1）

## 4. 会話

- **S08-18** 見出しは誰に届くかを名乗る（「開発（3 人）へ」）。自分しか居ないルームで「〇〇へ」と出さない（D107）
- **S08-19** 届く先を 1 人ずつ並べる。1 人なら 1 対 1、3 人なら 1 対 3 と読める（`04` S04-1）
- **S08-20** この機械から出た発言は右、ほかの機械からは左。会議からの知らせは吹き出しにしない。エージェントの発言には字で印を付ける（`02` S02-5）
- **S08-21** 差出人は名簿の名前で出す。同じ人が 1 通目は名前・2 通目は鍵、と出ない
- **S08-22** 相手ごとの会話があるように見せない（預かり所ごしの 1 対 1 だけは例外・§7.1）
- **S08-23** 留守中に届いた分には印を付け、出した側の時刻で出す。いま届いたように見せない（D72）
- **S08-24** 届き札は 渡した／預けた／届かない の 3 つだけ。既読は出さない（`02` S02-6）
- **S08-25** 届く先が無いときは、送る押し所を押せない。打ち込みは残す

## 5. 会議（映像と音）

- **S08-26** 会議の面は、隠しても音を止めない（畳まない・§7.1）
- **S08-27** 窓ごとスクロールさせない。動くのは列の中だけ。映像は縦の中央（§7.1）
- **S08-28** 経路（直接か中継か）は、色・字・形の 3 つで出す（§4.1）

## 6. 更新

- **S08-29** 新しい版があることは帯で言い、黙って入れ替えない（`05`）
- **S08-30** この PC の `warifu` コマンドが古いときは、帯でそう言う。入れ替えられるときだけ押し所を出す（`05` S05-23）
