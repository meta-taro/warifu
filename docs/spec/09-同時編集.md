# 09 同時編集 —— 割符が運ぶもの

文書を同時に直す道具（エディタや表）は、割符の机の線（同じ PC の割符への接続）に繋ぐ。
**割符は運ぶ道・居場所・写しを揃えることを持ち、文書の中身・検め・画面は道具が持つ。**
段は ①居場所（書き換えない）→ ② Markdown の同時編集 → ③ 表の行単位。いまあるのは ①。

## 1. 居場所（0.1.43）

誰が、どの文書の、どこに居るか。**割符は文書の名前も場所も読まない**（形は道具が決める）。

- **S09-1** 道具が机の線で `居場所 { 文書, 場所 }` を言うと、同じ部屋の相手の機械で `居場所を聞く` と言った線に、`居場所 { 誰, 文書, 場所, room }` が届く。誰は割符が刻む（道具は名乗れない）
- **S09-2** `居場所を聞く` と言っていない線（エージェント）には、居場所は流れない
- **S09-3** 1 つの線から速く来た居場所は、0.2 秒ごとに文書ごとの最後の 1 つにまとめて運ぶ
- **S09-4** 場所が空 ＝ 閉じた。道具の線が切れたら、その線が開いていた文書を閉じたとして流す。相手が部屋を抜けたら、その相手の居場所を閉じたとして流す
- **S09-5** 後から部屋に入った相手には、その部屋のいまの居場所をまとめて 1 回送る
- **S09-6** 客どうしの居場所も届く（主催が配り直す）。直接の線と主催ごしの 2 本で届いても、線へ渡すのは 1 回
- **S09-7** 文書の名前と場所はそれぞれ 512 バイトまで。行を壊す字（制御文字）は運ばない。文書の名前は空にしない
- **S09-8** 居場所の知らせを知らない古い版（〜0.1.42）は、それを読み飛ばす（会話も名簿も止まらない）

## まだ決めていないこと

- 相手の線が黙って切れた（抜けずに落ちた）ときの居場所の片付け（いまは抜けたときだけ閉じる）
