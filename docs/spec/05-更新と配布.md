# 05. 更新と配布 —— 版を上げても、誰も取り残さない

> 版を配るたびに、入れ替え忘れ・版ずれ・互換切れで「繋がらない」が起きた（0.1.37〜0.1.40 の週ごとの実測）。
> ここでは**配る側と受け取る側の約束**を、人が確かめられる文で固定する。

## 1. 版の単位

- **S05-1** 版は週 1 回、金曜にまとめて出す。直しは細かく刻まず 1 版に束ねる（版ごとに約 1 時間止める保護ソフトがある機械のため）
- **S05-2** 画面（`warifu.app` / `.exe`）と `warifu` コマンド（口・常駐・預かり所）は**同じ版番号**で出す。片方だけ上げる版は出さない
- **S05-3** 版の番号は `Cargo.toml` の 1 か所で決め、画面の題字・`warifu version`・口の `about` の末尾がすべて同じ数字を出す

## 2. 新しい版に気づく

- **S05-4** 画面は起動時と **1 時間ごと**に新しい版があるか向こうへ尋ねる。見つけても**勝手には入れ替えない**（入れ替えは立ち上げ直しを伴う。押すのは人）
- **S05-5** 新しい版があれば、画面に帯（版・何が変わったか・［再起動して更新する］）が出る。帯は人が閉じるまで残る
- **S05-6** 人は、連絡帳の「いまの様子」の［更新を確認する］で、いつでも確かめられる（Windows の窓にはメニューが無い）
- **S05-7** エージェントは `update_check` で同じことを確かめられる。新しい版があれば画面に帯が出るので、エージェントは人へ「帯を押してください」と頼む。**入れ替えそのものは人が押す**
- **S05-8** `.app` の外で動いている画面（開発中など）は、更新を確かめない（入れ替えると置き場所が消える）

## 3. 入れ替える

- **S05-9** 画面の入れ替えは、画面が自分で落として入れ替え、人が［再起動して更新する］を押したときに立ち上げ直す
- **S05-10** `warifu` コマンドは画面とは別のファイルなので、画面を上げても古いまま残る。画面は 1 時間ごとに同じ機械のコマンドの版を見比べ、古ければ**名指しで**（場所と版を書いて）人へ言う。新しければ「画面を上げて」と言う
- **S05-11** macOS で `warifu` コマンドを入れ替えるときは、**消してから置く**（上書きすると起動しなくなることがある）。画面の文言もそう言う
- **S05-12** コマンドを入れ替えたら、動いている `warifu mcp`・`warifu agent`・`warifu relay` も立て直す。Claude Code の口は `/mcp` の繋ぎ直しで入れ替わるが、古い口が残ることがあるので、数えて止める
- **S05-13** 版が上がって最初の立ち上げで、画面はこの PC のエージェントへ 1 度だけ「版が上がった。`room_status` と `app_view` を見比べて」と頼む（04 の S04-12）

## 4. 互換

- **S05-14** 相手の機械と交わす形（知らせの形・口と画面の間の行の形・鍵の形）を変える版は、CHANGELOG のその版の節に「互換」の項を書く。切れないなら「互換：切れない」と 1 行書く
- **S05-15** 新しい欄は**名乗った相手にだけ付ける**（古い読み手は知らない欄で行ごと読めなくなるため）。古い相手に断られたら、欄なしで名乗り直す
- **S05-16** 互換が切れうる版は、**配る前に**全機の部屋へ 1 行流す（どの版から・何が変わるか・古い版とどう混ざるか）
- **S05-17** 古い版の相手と混ざって動いても、繋がらなくはならない。新しい側が古い側に合わせる（部屋 id を添えた叩き・部屋の欄・点検の欄）

## 5. 版ごとの説明

- **S05-18** 版ごとに CHANGELOG に「直したもの／何が起きていたか」の表を書く。リリースの本文にも同じ表を載せる
- **S05-19** 口の `changes` は版ごとの変更をそのまま返す。エージェントは「直ったはず」と「直っていない」を版の違いとして自分で確かめられる
- **S05-20** 出す前に `scripts/release-gate.sh <版>` を通す（全試験・CHANGELOG の節・互換の記述・配布の文書の版・公開してはいけない語・作業の木）。通らない版はタグを打たない

## 6. 配ったあと

- **S05-21** 配ったら、全機の部屋に版と「何が直ったか」を 1 行流し、各機械の席は入れ替えたら版を 1 行返す。全機が揃ったことを数えてから、人を呼ぶ試験を組む
- **S05-22** 入れ替えたのに直らない報告は、まず版を疑う（画面・コマンド・口の 3 つの版を揃えて確かめる）
