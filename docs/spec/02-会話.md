# 02. 会話 —— 番号・届き・未読・下書き

> あるべき形。番号は `S02-n`。守っている試験は `invariants.tsv`。

## 1. 発言

- **S02-1** 机の発言には番号が付き、**立て直しても続きから**振る。番号は巻き戻らない
- **S02-2** 部屋を替えても、打ちかけの文は**部屋ごと**に控え、混ざらない
- **S02-3** 人が自分で部屋を替えたら、宛先の据え置きはしない
- **S02-4** 発言はちょうど 1 つのルームに属する（`00` S00-1）。別のルームの欄に出ない
- **S02-5** 自分の発言は右、ほかは左。エージェントの発言は点線と札で分かる

## 2. 届き

- **S02-6** 届き札は **渡した／預けた／届かない** の 3 つ。**既読は作らない**（人の画面に出たことは、人が読んだことではない）（`@` で呼んだ行の「受けた」は S02-30）
- **S02-7** 相手が起動していなければ、留守中の受け取り（預かり所）があるときだけ「預けた」。無ければ「届かない」。「たぶん届いている」は無い
- **S02-8** `@名前` は届く先を変えない。呼ばれた側にだけ「あなた宛て」の印と OS 通知。候補は入力中に出る

## 3. 未読

- **S02-9** 未読は相手ごとに数え、相手へは送らない
- **S02-10** 見ているルームの新しい発言は、下に居れば自動で追い、上に居れば「新しい発言」の札で知らせる

## 4. 残す

- **S02-11** 会話は各機械に残す。立ち上げ直しても（版の入れ替えを含む）、前の会話の続きに新しい発言が並ぶ。上限はルームごとに 30 日または 5,000 行の早いほう（D127）。別の日の行には日付を添える（0.1.44。0.1.43 までは画面の記憶の中だけで、立ち上げ直すたびに消えていた）
- **S02-12** 保存は機械の鍵で封をし、自分だけが読める置き方にする。記録（`warifu.log`）には中身を書かない（数だけ）。開けない控えは上書きせず脇へ退け、空から始めたことを画面に出す
- **S02-11a** 画像はまだ残さない。立ち上げ直したあとは「画像があった」ことだけを出す（D127 の画像の上限 7 日・200 MB は未着手）。エージェントが読める会話（`chat_read`・`chat_export`）は、起動してからの直近の分だけ
- **S02-13** 繋ぎ直したエージェントは、切れていた間の発言を**続きから**受け取る（番号の控え）

## 5. 画像

- **S02-14** 画像は文字と同じ道を通る（主催ごしの配り・名簿の確かめ）
- **S02-15** 会話には、画像が来たことを 1 行の札で流す（番号と見方を添える）。エージェントは札の番号で `chat_image` を呼んで画像そのものを見る（0.1.43。前は札だけで、画像を共有しても話が通じなかった）。この機械が覚えるのは直近 20 枚で、手元の記憶の中だけ（ファイルに書かない）。無い番号には、無いと返す
- **S02-29** 発言のマークダウン（見出し・太字・符・符の囲い・箇条・引用・表・罫）を描く。HTML にはせず、届いた文のタグは字のまま出す。繋ぎは押せない（先は指すと出る）。マークダウンの無い発言は、打った改行ごとそのまま（0.1.44）
- **S02-30** `@` で呼んだ行にだけ、呼ばれた側から「受けた」が返る。返るのは、人が［受けました］を押した・その部屋で返事を書いた・エージェントがその行を読んだ、のどれかのときだけ。画面に出ただけでは返らない（既読ではない）。呼んだ側の行には「{名} が受けた」か「まだ受けていない（N 分）」が出て、30 分で注意の色になる。呼んでいない発言には何も返らない（0.1.44）
- **S02-16** 人は、大きく見た画像を［ダウンロードに保存］で手元に残せる。同じ名があれば番号を足し、上書きしない。保存した場所を画面に出す

## 留守中の分（Issue #1・0.1.42）

- **S02-20** 主催は、線が切れた（抜けたのではない）面々あての文字を預かり、その人が入り直したら順に 1 回ずつ渡す。渡したら消す
- **S02-21** 自分で抜けた人・畳んだ部屋の分は預からない。預かるのは文字だけ（画像は預からない）。1 人ぶん 200 件まで、超えたら古い分から落とす
- **S02-22** 入り直す客は、参加より先に「この部屋の文字をここまで持っている」（最後の文字の印）を主催へ言う。主催は、その印より後で、その客が部屋に入った後の文字を順に 1 回ずつ送り直し、預かりを消す。主催が線の切れに気づく前（およそ 30 秒）の分も、上がり直した後も届く（印は控えのファイルに置く）
- **S02-23** 印を持たない客・部屋に居たことの無い客・控えに無い印には送り直さない（預かり分だけ）。見たことのある発言が 2 度届かないこと、入る前の発言が見えないことを優先する。主催は部屋ごとに直近 200 件の文字を控える
- **S02-24** 主催が流した発言の届き方（`chat_status`）には、線が切れて預かっている相手を「まだ届いていない」と並べる。入り直して預かり分を渡したら「届いた」へ移す。客から見た主催の向こうの相手は「主催ごし」と書く。`chat_send` の返りの形は変えない（古い口が「相手が居たか」を読む）
- **S02-25** 送った発言は取り消せない（届いた各機械に写しが残る）。だから送る前に、秘密らしいもの（長い 16 進・`TOKEN=` のような名前と値・名の知れた API キーの形・プライベートキー・ルームキーの全文）を見る。エージェント（`chat_send` と本体の流し口）は送らずに止め、値を言い返さない。人の画面は打った文を欄に残したまま確かめ、［それでも送る］を押したときだけ送る。見る決まりは本体と画面で同じ（同じ例文の表で試す）
- **S02-26** エージェントの `chat_send` は、発言を渡せたのに失敗を返さない。相手の線が詰まっていても、口の待ち（5 秒）より先に返り、詰まった相手は「まだ届いていない」に数える
- **S02-27** 長すぎる発言は、この機械へつなぐ前に「長すぎます」と上限を添えて断る（ほかの断りと同じ文にしない）
- **S02-28** 長い発言（8 行か 400 字を越える）は頭だけ見せ、［もっと見る］／［たたむ］で開け閉めする。改行は Shift+Enter で打てると、どの打つ欄にも出す
