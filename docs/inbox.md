# 受信箱を測る（**段 1・自分のメールで動かす**）

> **相手が要りません。**P2P も会議も使わず、**自分の受信箱 1 つ**で動きます
> （`PRD §2` /`PRD §12-5`「切り分けは『P2P が要るか』で引く」）。
>
> **AI は資格情報を作らない・置かない・貼らない**（baseline §14）。値を入れるのは人です。
> **実測値の記入も人が行います**（baseline §19 / §29）。AI は代筆しません。

---

## これは何をするか

受信箱を 1 回ぶん読んで、**今日、人間が判断することだけ**を出します。

- **本文は 1 文字も表示しません。**出るのは metadata（差出人・種別・要判断か）だけ
- **AI を呼びません。**規則で判定できるものは、モデルに渡しません（**D19**〜**D23**）
- **token の会計を書き足します。**「AI を呼ばないと、どれだけ減るか」を実測するためです

**メールを変更しません。**返信・削除・既読を付ける口を持っていません（`BODY.PEEK[]`・**D23**）。

---

## 1. 値を入れる

```bash
cp .env.example .env
```

`.env` を開いて、自分の受信箱の値を入れます。**`.env` はコミットされません。**

| 変数 | 何を入れるか |
|---|---|
| `WARIFU_IMAP_HOST` | 例: `imap.gmail.com` |
| `WARIFU_IMAP_PORT` | 省略すると `993` |
| `WARIFU_IMAP_USER` | メールアドレス |
| `WARIFU_IMAP_PASSWORD` | **アプリ用パスワード**（下記） |
| `WARIFU_IMAP_LIMIT` | 1 回に取り込む上限（省略すると 50） |
| `WARIFU_LEDGER` | 会計の書き足し先（省略すると `warifu-ledger.tsv`） |
| `WARIFU_RULES` | 承認済みの規則（省略すると `warifu-rules.tsv`。無ければ規則なしで進む） |

**Gmail / Outlook は通常のパスワードでは入れません。**アプリ用パスワードを発行してください。
2 段階認証を有効にしてから、アカウントの設定で「アプリ パスワード」を作ります。

---

## 2. 回す

```bash
set -a; . ./.env; set +a
cargo run -p warifu-imap --example inbox
```

出るもの（実際の形）——

```
承認済みの規則 0 件（warifu-rules.tsv）

── 今日、人間が判断すること ──
  invoice      billing@example.com
  開かない 43

取り込み 50 通 / 解釈器を呼んだ 0 回 / token 0 + 0
会計を書き足しました: warifu-ledger.tsv
```

**「開かない」が多いほど良い。**それが「AI を呼ばずに済んだ通数」です。

---

## 3. 記録してほしいこと（**人が書く**）

`issues/007` の最後の完了条件は「**実際に自分の受信箱で 1 週間使い、token の実測値を人が記録した**」です。

1 日 1 回まわして、`warifu-ledger.tsv` を貯めてください。**1 週間ぶんが要ります。**

書いてほしいのはこの 3 つです。**AI が代筆しません。**

| | |
|---|---|
| **取り込み通数と「開かない」の比** | 規則がどれだけ効いたか |
| **判断が要ると出たのに、実は要らなかったもの** | 規則の作り直しに要ります。**件名ではなく差出人で書いてください** |
| **判断が要らないと出たのに、実は要ったもの** | **これが一番重い。**取りこぼしです |

---

## 4. うまくいかないとき

| 症状 | 見る所 |
|---|---|
| `WARIFU_IMAP_HOST が設定されていません` | `set -a; . ./.env; set +a` を打っていない。`.env` を `cargo` へ渡す一手間が要ります |
| 認証で落ちる | **通常のパスワードを入れていないか。**アプリ用パスワードが要ります |
| 0 通しか取れない | 未読が無い（`fetch_unseen` は**未読だけ**を見ます） |
| 種別が全部 `unknown` | 規則がまだありません。**それで正常**です。`WARIFU_RULES` に承認済みの規則を置くと変わります |

---

## 5. **まだ一度も実サーバへ繋いでいません**

`warifu-imap` の試験は**自分で書いた台本**を読ませているだけです（**D23**）。
**実在のサーバがそのとおり返す保証はありません。**ここで初めて分かります。

**繋がらなかったら、それ自体が成果です。**エラーの全文を `issues/007` に貼ってください。
