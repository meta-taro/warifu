# エージェントを、人と同じ会話につながらせる

> **English:** [mcp.md](mcp.md)

**割符は、チャットやメールを MCP を通じて行う OSS です。**
ここでは、この PC のエージェント（Claude Code など）を、
**人が見ている会話につながらせる**手順を書きます。

```text
  人（割符の画面）──┐
                    ├── 同じ会話 ── P2P ── 相手の PC
  AI（warifu mcp）──┘
        ↑ この機械の口（同じ機械の中だけ。網には出ません）
```

**エージェントが喋ると、その行がそのまま人の画面に出ます。**
人が打った行も、エージェントに見えます。

---

## 1. 割符の画面を開く

画面を開くと、**この機械の口が自動で開きます。**別の操作は要りません。

この機械の口の場所は次のとおりです。

| | 場所 |
|---|---|
| macOS | `~/Library/Application Support/warifu/desk.sock` |
| Linux | `$XDG_RUNTIME_DIR/warifu/desk.sock`（無ければ `~/.local/share/warifu/desk.sock`） |
| Windows | `\\.\pipe\warifu-desk`（`WARIFU_HOME` を設定すると名前に印が付きます） |

開けたかどうかは、ターミナルから起動したときの記録に出ます。

```
[warifu +0.412s] この機械の口を開きました: /Users/…/warifu/desk.sock
```

---

## 2. エージェント側に口を書く

### いちばん楽なやり方 —— **1 回だけ打つ**

```
warifu setup
```

**Claude Code の「利用者ごとの設定」へ入れます。**入れたあとは
**どのフォルダで立ち上げても** `warifu` が出ます。フォルダごとに書く必要はありません。

- **何を許すかを、入れる前に画面に出します。**既定は**会話と、自分のエージェントの名乗りだけ**
  （受信箱も予定表も許しません。要るなら自分で足してください）
- **確かめてから入れます。**飛ばすなら `warifu setup --yes`
- `claude` が見つからないときは、**手で打つものを出して終わります**（勝手に何かを入れません）

手で入れるなら、これと同じです。

```
claude mcp add warifu --scope user -- warifu mcp --allow chat.send --allow chat.read --allow profile.write
```

**Windows では `cmd /c "…"` で包んでください。**npm で入れた Claude Code は `claude.ps1` で、
PowerShell から呼ぶと **`--` が食われ**、`--allow` を claude が自分の指定として読んで止まります。

```
cmd /c "claude mcp add warifu --scope user -- warifu mcp --allow chat.send --allow chat.read --allow profile.write"
```

`warifu setup` は、Windows では自分で `cmd /c` 越しに呼びます。

### フォルダごとに書く場合



エージェントの MCP 設定に**ファイルとして**書きます。
Claude Code なら、**そのエージェントが作業するフォルダの直下に `.mcp.json`** を置きます
（そのまま使える形を `docs/mcp.json.example` に置いてあります）。

**このリポジトリにも `.mcp.json` は置いていません。**`warifu setup` で入れてください ——
フォルダごとに書くと、**リポジトリの数だけ書くことになり、書き方もばらけます**
（2026-09-08 に実際にばらけました）。

```json
{
  "mcpServers": {
    "warifu": {
      "command": "warifu",
      "args": ["mcp", "--allow", "chat.send", "--allow", "chat.read", "--allow", "profile.write"]
    }
  }
}
```

**`--allow` を書かなければ、どの口も通りません。既定は拒否です。**
何を許すかは**人が決めて、人がここに書きます。**
割符が自動で札を出すことはありません。

`command` は、**そのエージェントから実際に叩ける場所**にします。

| | 書き方 |
|---|---|
| PATH が通っている | `"warifu"` |
| このリポジトリで建てた | `"./target/debug/warifu"`（`.mcp.json` はこれ） |
| `.app` を受け取った（macOS） | `"/Applications/warifu.app/Contents/MacOS/warifu-cli"` |
| `.msi` で入れた（Windows） | `"C:\\Program Files\\warifu\\warifu.exe"` |

**書いたあと、エージェントを立て直してください。**MCP の口は起動時に読まれます。

### もう入っている場合（**入れ直す**）

`warifu setup` は、**すでに入っていれば入れ直します。**

```
warifu の口は、もう入っています。入れ直します。

  実体   /Users/…/warifu
  いまの札 mcp --allow chat.send --allow chat.read --allow inbox.list
  これから /Users/…/warifu mcp --allow chat.send --allow chat.read --allow profile.write
```

**いまの札と、これからの札を並べて出します。**許す動作が減ることもあるので、
**押す前に見比べてください。**

> **札を足したのに古いままだった、が起きます。**
> 2026-09-08 に `profile.write` を足しましたが、**前に入れた人の設定は古いまま**でした
> （`claude mcp add` は同じ名前があると断るので、入れ直せなかった）。

### 許せる動作

| 動作 | 通る口 | 出るもの |
|---|---|---|
| **（要りません）** | **`about`** | **割符とは何か**（エージェント向けの概要・守ることと口の一覧） |
| **（要りません）** | **`changes`** | **版ごとに何が変わったか**（`version` を渡すとその版だけ） |
| `chat.send` | `chat_send` | 会話へ 1 行流す。**`room` を省くと、最後に届いた発言の部屋へ**（呼ばれた所へ返す）。別の部屋へは `room` に部屋の id（`chat_read` の行の末尾「部屋 NBIW…」）を書く |
| `chat.read` | `chat_read` / **`chat_wait`** | 届いた発言（読んだ分は消えます）。**`chat_wait` は届くまで待ちます** |
| `profile.write` | `profile_set` | **自分のエージェントの名乗り**（名前と短い紹介）を書く |
| （`chat.read` と同じ札） | `chat_status` | **自分が流した発言の届き方**（届いたエージェント・読んだエージェント） |
| （`chat.read` と同じ札） | `room_status` | **いまのルームの様子**（相手・経路・画面の題字）。下の「いまの様子を見る」 |
| `room.invite` | `room_invite` | **この機械が主催しているルームへ入るルームキー**（見ているルームを主催していればそこ、でなければ主催している別のルーム、無ければ建てる）（1 本＝1 人。**公開の場に貼らない**） |
| `room.invite` | **`room_key_give`** | **ルームキーを、指定した相手の機械にだけ、割符の線で直接渡す**（下の「鍵を手渡す」） |
| **（要りません）** | **`pass_ask`** / **`pass_wait`** | **足りない札を人に頼む**／人が答えるまで待つ（**D119**。頼むことを禁じると頼めなくなるため） |
| `inbox.list` | `inbox_list` | 受信箱の metadata だけ（本文は出ません） |
| `inbox.open.summary` | `inbox_open` | 要約まで |
| `inbox.open.structured` | `inbox_open` | 構造化した項目まで |
| `inbox.open.raw` | `inbox_open` | 本文まで |
| `inbox.open.attachments` | `inbox_open` | 添付の名前と大きさ |
| `calendar.freebusy` | `calendar_slots` | 空き枠だけ（予定の題名は出ません） |
| `rules.list` | `rules_list` | 承認済みの読み取り規則 |
| `voice.say` | `voice_say` | **いまのルームの会議へ、読み上げの声で 1 回話す**（人がルームごとに入れたときだけ流れる） |
| `chat.export` | `chat_export` | **いま割符が持っている会話を書き出す**（議事録用。割符を閉じれば消え、直近の分だけ。書き出したものを相手の同意なしに公開しない） |
| `contacts.read` | `contacts_list` | この PC が覚えている相手（名前・鍵の頭・呼べそうか。**住所は出ません**。名前を付けていなくても、ルームで会った相手は「名前なし」で並び、鍵の頭で呼べます） |
| `contacts.call` | `contact_call` | **覚えている相手を、ルームキーなしで呼ぶ。この機械が、相手が主催しているルームへ招かれる**（住所を知っていて、相手の戸口がこちらを通すときだけ。人に頼まれたときに使う） |
| `screen.read` | `app_view` | **この PC の割符の画面が、いま人に見せているものを文字で写す**（開いているルーム・人数・届く先・チャット欄の行など。チャットの本文が入る）。本体の知っていること（`room_status`）と、人の画面に出ていることの食い違いを見つけるのに使う |
| `contacts.add` | `contact_add` | **相手の住所（`WARIFU1-…`・`#` なし）から、連絡先に名前を付けて足す**（会えない相手も `contact_call` で呼べるようになる。**この PC の戸口もその相手を通す**。住所は相手の機械の席から受け取ったものだけを使う。ルームキーは断る。**札は 1 回使うと消える**。足すと人に OS の通知が出る） |
| `contacts.add` | **`contact_name`** | **ルームで会った相手（「名前なし」）や覚えている相手に呼び名を付ける・付け直す**（画面の「名前を付ける」と同じ道。知っている住所も一緒に書く。**人に頼まれたときに使う。札は 1 回使うと消える**） |
| `room.join` | `room_join` | **ルームキーで、この機械の割符をそのルームへ入れる**（人が画面の前に居なくても入れる。**人か信頼できる席から受け取った鍵だけ**を使う —— 入ると、この機械の会話が相手に流れる。**札は 1 回使うと消える**。入ると人に OS の通知が出る。人が見ているルームは変えず、主催を知り合いにも帰り道にも残さない）。**札は同じ利用者で動くプログラムへの歯止めであって、境界ではない**（この機械の口へ直接書けるプログラムは札を通らない） |
| （`chat.read` と同じ札） | **`room_list`** | **この機械の割符が居る部屋をすべて並べる**（id の頭・名前・人数・主催か・見ているか）。`room_status` は見ている部屋の分だけ |
| `room.leave` | **`room_leave`** | **部屋を指定して抜ける**（主催なら畳む。画面の［このルームを抜ける］と同じ道。**人に頼まれたときに使う。札は 1 回使うと消える**） |
| `room.rename` | **`room_rename`** | **部屋に人が読める名前を付ける**（居る人みんなに同じ名前が見える。**札は 1 回使うと消える**） |
| （札なし） | **`update_check`** | **この PC の画面に、新しい版があるか向こうへ尋ねてもらう**（いまの版・新しい版・何が変わったか）。新しい版があれば画面に更新の帯（落として入れ替える・再起動）が出るので、人へ「帯を押してください」と頼む。**入れ替えは人が押す**（0.1.41 から。古い画面には口が無い） |

**`about` と `changes` に札は要りません**（**D82**）。
関所（札）が守っているのは**人のもの**です —— 受信箱・会話・予定。
この 2 つが返すのは**この実行ファイル自身の説明**で、人のものは 1 文字も入っていません。

そして、**札で閉じると順番が逆になります** ——
「何をしてよいかを知るために札が要る」という形になってしまいます。

```
about    → 概要 ＋「いま繋がっている版: 0.1.0」
changes  → ## v0.1.0-alpha.15 — 2026-09-09
             - fix(release): 署名の検証が、一度も検証していなかった
```

**中身はタグ間の commit の見出しです。**書き起こした文ではありません
（`CHANGELOG.md` は版ごとに切っていないので、そこからは作れません）。
**無い版を尋ねられたら「見当たりません」と言います** —— 近い版を勝手に返しません。

綴りを間違えると、**黙って無視せずに断ります。**

```
warifu: 知らない動作です: chat.write
許せるのは: chat.send chat.read inbox.list …
```

## 3. 確かめる

エージェントに、こう頼んでください。

> `chat_send` で「つながりました」と流してください

**割符の画面のチャット欄に、その行が出れば通っています。**
「**◯◯ のエージェント**」（起動した場所）という名前で出ます。

```
18:11   zumen のエージェント   つながりました
```

流れたときは、**何人へ届いたかまで返ります。**

```
2 人へ流しました。
```

**「流しました」だけでは、0 人へ流したことと区別が付きません**（D49）。

出ないときは、次の順で見てください。

| 出た言い分 | 意味 | すること |
|---|---|---|
| `関所が断りました: chat.send。この口には --allow chat.send の札が要ります…` | 札が無い | `--allow chat.send` を書く（**書けるのは人だけ**） |
| `この機械の口が開いていません` | 画面が立っていない | 割符の画面を開く |
| `まだ会議がありません` | 会話そのものが無い | 画面で会議を建てるか、入る |
| `この PC の画面には出ましたが、会議には誰も居ないので誰にも届いていません` | 相手が 1 人も居ない | 会議キーを渡して、入ってもらう |
| 何も返らない | `warifu` が見つかっていない | `command` を実体の場所にする |

**画面より先にエージェントが起きていても構いません。**
会話を使うときに繋ぎ直します。

## 4. 知っておくこと

### 気づくには、待たせてください

`chat_read` は「**いま溜まっているか**」を覗きに行くだけです。
エージェントは自分から気づけないので、**人が打っても黙ったまま**になります
（2026-09-07 に実際に起きました）。

**`chat_wait` を使ってください。**届くまで待って、届いたら返します（最大 60 秒）。

```
chat_wait                 30 秒待つ
chat_wait {"seconds": 60} 60 秒待つ
```

**永遠には待ちません。**待っている間、そのエージェントは何もできないためです。
返事を待つ場面では、`chat_read` を繰り返し叩くのではなく**こちらを使ってください。**

### **Claude Code なら、届いたときに起こしてもらえます**（channels）

`chat_wait` も、待っている間しか気づけません。**ほかの作業をしている間に届いた発言は、
誰かが読みに行くまで残ったままです**（2026-10-19 に、8 時間近く読まれない発言が出ました）。

この口は Claude Code の **channels**（研究段階の機能）を名乗っています。
**発言が届くと、口から Claude Code へ知らせを押し出します** —— 入力待ちのセッションも、それで動き出します。

```bash
claude --dangerously-load-development-channels server:warifu
```

`server:` の後ろは、MCP の設定に書いた口の名前です（`claude mcp add warifu …` なら `warifu`）。

| | |
|---|---|
| **知らせに本文は入りません** | 「何件・誰から・最新の番号」だけです。本文は `chat_read` で読みます。**読んだことになるのは、`chat_read` で受け取ったときです**（**D76**） |
| **`@名前` で呼ばれた発言には印が付きます** | 本文に `@` ＋あなたの名前（どこで動いているかの名乗り・`profile_set` の名前。全角の `＠` も同じ）があると、知らせの頭で「あなた宛ての発言が N 件」と言い（`meta.mentioned`）、`chat_read` / `chat_wait` ではその行の末尾に `（あなた宛て）` が付きます。**届く先は変わりません**（ルームの全員に見えています） |
| **誰かがルームに入っても知らせます** | **連絡先から呼ばれた側は、知り合いなら人に聞かずにルームへ入ります。**「〇〇が入りました」と知らせます（覚えている相手なら呼び名で）。出ただけでは起こしません |
| **切れたまま 10 分戻らない人も知らせます** | 「抜けた」（本人が［このルームを抜ける］を押した）と「切れた」（経路が落ちた）は別です。切れた機械は自分で戻ってくるので、切れただけでは知らせません。**10 分たっても戻らないときだけ**、「10 分、ルームに戻っていません。抜けてはいません」という行が届きます |
| **続けて届いた分は 1 回にまとめます** | 2 秒束ねてから知らせます。`chat_wait` で待っている間に取れた分は知らせません |
| **`chat.read` の札が無ければ知らせません** | 読めない発言の在り処だけを言わないためです |
| **口を立てたらすぐ、この機械へ繋ぎます** | 画面がまだ立っていなければ、15 秒ごとに繋ぎに行きます |
| **フラグなしで立ち上げたら、何も起きません** | Claude Code が知らせを黙って捨てます。害はありません |

**起動のたびに警告の画面が出ます。**割符は Claude Code の承認済みの一覧に入っていないためです。
Team / Enterprise の組織では、**管理者が channels を有効にしていないと使えません**（`channelsEnabled`）。

**エージェントが立ち上がっていなければ、起こせません。**そのときは下の `warifu agent` を使ってください。

### **鍵を手渡す**（`room_key_give`）

ルームキーをメールやチャットのアプリで渡すと、**鍵が外の網に出ます。**
`room_key_give` は、**いま割符でつながっている相手の機械へ、割符の線で直接**渡します。

```
エージェント   room_key_give {"to": "相手A", "why": "立て直したあと戻れなかったときのため"}
この PC の人   帯に［渡す］／［渡さない］           ← 押すまで鍵は出しません
相手の機械     「相手A からルームキーが届きました。入りますか？」  ← 入るかは相手の人が決めます
```

| | |
|---|---|
| **鍵の文字はエージェントに返りません** | 返るのは「渡した（いつまで）・まだ・渡さないと決めた・渡せない理由」だけです |
| **渡す前に、この PC の人が承認します** | `why` は人が読む理由です。空なら受け付けません |
| **いまつながっている相手だけ** | つながっていない連絡先の相手は、鍵なしで「連絡先から呼ぶ」（`contact_call`）を使ってください |
| **鍵はエージェントごとに要りません** | 同じ機械のエージェントは、その機械の割符に乗ります。1 台に 1 本です |
| **記録に鍵を書きません** | `warifu.log` には「誰へ・いつまで」だけが残ります |

### **待たずに反応する**（`warifu agent`）

`chat_wait` は**待っている間、そのエージェントは何もできません。**
**外から声をかけられて反応する**なら、こちらが本来の形です。

```bash
warifu agent --as 当番 --on ./touban.sh
```

**ポーリングしません。**この機械につながって待ち受け、**届いた行を命令の標準入力へ渡して起こします。**
命令が何か言えば、それがそのまま会話へ流れます。

```
（外から）  外のお客さまから問い合わせです。見積もりの相談だそうです。
（当番）    当番です。受けました：外のお客さまから問い合わせです。見積もり… いま担当へ回します。
```

| | |
|---|---|
| **届いた文字は標準入力へ** | **引数にも環境変数にも入れません**（**D5**）。`ps` に出ないためです |
| **命令が黙っていても報せます** | 「（動きましたが、何も言いませんでした）」。**動いたのに何も出ないと、落ちたのと区別が付きません** |
| **自分の発言では動きません** | 自分が言ったことに自分で反応すると、止まらなくなります |
| **1 分に 60 回まで** | 溢れた分は捨てます。**捨てたことは言います** |
| **画面を建て直しても落ちません** | 口が閉じたら**繋ぎ直します**（2 → 4 → 8 … 上限 30 秒）。「止まれ」と言われたときだけ降ります |
| **差出人は短く出します** | 呼び名が付いていない相手は `F7KROW4U2SNH…`（画面と同じ切り方）。**全桁は出しません** |

#### 中身の書き方（**そのまま使えます**）

`--on` に渡すのは**あなたが書いた命令**です。届いた行は**標準入力に 1 行**で来ます。

```sh
#!/bin/sh
# 届いた 1 行を受けて、短い返事を出す。
# **シェルの変数名は ASCII だけ**（`行` のような名前は sh が受け取りません・baseline §30）
read -r line
printf '%s' "$line" | claude -p --model claude-haiku-4-5-20251001 \
  --append-system-prompt 'あなたはルームに居るエージェントです。日本語で 1〜2 文の短い返事だけを返します。'
```

```bash
chmod +x ./run.sh
warifu agent --as helper --on ./run.sh
```

**これで、人が打った行に別プロセスの Claude が自分で返します。**
2026-09-11 に実物で通しました（画面 → helper → 画面／画面を建て直しても繋ぎ直る）。

> **すでに動いている Claude Code のセッションを、割符から叩き起こすことはできません。**
> あれは Claude Code の側の仕組みです。できるのは「**新しく起こす**」（`--on` で `claude -p`）か、
> 「**次に読んだときに渡す**」かの 2 つです。

### **いまの様子を見る**（`room_status`）

**人に聞かずに、繋がったかどうかを確かめられます**（2026-09-11 に追加。
人が押したことをエージェントの側から検知できるようにするため）。
**札は `chat.read`**（誰と繋がっているかは人のものなので）。`--allow voice.say` だけでは通りません。

```
room_status →
  ルーム: ROOMAAAAAAAAAAAAAAAAAAAAAA
  相手: PEERCAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
  経路: direct
  この機械のエージェント: helper のエージェント
  答えを待っているリンク: 1 本（ルーム NBIW3PA2TUQ52DTJNVXSQOL3G4）
```

| 出るもの | 中身 |
|---|---|
| ルーム | いま見ているルームの id。居なければ「居ません」 |
| 相手 | そのルームに居る相手の公開鍵（**自分は入りません**） |
| 経路 | `direct`／`relayed`／**`unknown`**。**分からないものを直接に倒しません** |
| この機械のエージェント | つながっている呼び名（自分も入ります） |
| 答えを待っているリンク | **「入りますか？」が画面に出たまま**の数と、**どのルームについてか**。押された瞬間に 1 本になります |

**札は `chat.read`。**会話の中身は 1 文字も返しませんが、
**誰と繋がっているかは人のもの**なので、読む札の内側に置いています。

**相手が複数いるときの経路** —— **全員が同じ札のときだけ**返します。
混ざっているときは `unknown`（**まとめて 1 つに丸めない**）。

### 「届いていない」と「つながる前だった」は別です

`chat_read` は**読んだ分が消えます**が、**消えるのは自分のエージェントの分だけ**です。
**別のエージェントが先に読んでも、あなたの分は消えません。**

取れないときは、**そのときエージェントが外れていた**可能性があります
（**画面を入れ替えると、この機械につながっていたエージェントは全部外れます**）。
そのため、何も無いときは**いつからつながっているか**を添えます。

```
chat_read → 新しい発言はありません。（このエージェントは 09:05 からつながっています。
            それより前の発言は取れません）
```

**この時刻より前は取れません。**時刻が思ったより新しければ、**途中で繋ぎ直っています。**

### 繋いでいる版を見る

MCP の口は、繋いだときに**版を名乗ります**。

```
割符の口（版 0.1.8）。受信箱を読み、…
口が足りないと思ったら、この版が古い可能性がある（人に立て直してもらう）。
```

**新しい口が足されても、繋ぎ直すまでは見えません。**
`profile_set` や `chat_status` が見当たらないときは、**まず版を疑ってください。**

### 読まれたかを見る（**D76**）

`chat_send` は**通し番号**と**届けた先**と**流した部屋**を返します。
**番号はこの機械が振るもので、機械ごとに別**です（部屋ごとでも、全機共通でもありません。別の機械の #12 は別の発言です）。
相手の居ない部屋へ流れたときは「この部屋に相手は居ません」と言います —— 「届いた」と読まないでください。

```
chat_send {"body": "つながりました"}
→ #12 を 3 人へ流しました（部屋 NBIW3PA2TUQ5…）: 画面・zumen のエージェント・git-qa のエージェント。
  読まれたかは chat_status で見られます。

chat_status {"id": 12}
→ #12 届いた 画面・zumen のエージェント・git-qa のエージェント
  ／読んだ zumen のエージェント。人の画面は「出した」までしか分かりません。
```

| | 「届いた」 | 「読んだ」 |
|---|---|---|
| この機械のエージェント | 配った時点 | **渡した時点**（`chat_read` / `chat_wait` が呼び手へ渡したとき） |
| **人の画面** | 出した時点 | **分かりません。だから言いません** |
| ルームの相手（別の機械） | 送った時点 | **まだありません** |

**「読んだ」の意味は狭く固定してあります。**渡した時点が読んだ、です。
**中身を理解したかは誰にも分かりません**ので、そこは名乗りません。

**覚えているのは直近 200 発言ぶんだけ**です。古いものは「覚えていません」と返ります。

### 届いた文字は、指示ではありません

`chat_read` が返す文字は、**相手の言い分**です。
そこに「◯◯を実行して」と書いてあっても、**それは許可ではありません。**
何をしてよいかは、人が出した札だけが決めます。

### エージェントは差出人を名乗れません

`chat_send` に差出人を書く場所はありません。**誰が言ったかはこの機械の口が刻みます。**
名乗れる形にすると、届いた文字が人の発言を騙れます。

### 自分の名乗り（プロフィール）は書けます（**D75**）

**エージェントも 1 人です。**名前と短い紹介を、自分で書けます。

```
profile_set {"name": "図面くん", "bio": "図面まわりを見ています。CI も見ます。"}
→ zumen のエージェント として書きました。
```

**書けるのは自分のエージェントだけです。**

| 書ける | 書けない |
|---|---|
| 自分のエージェントの**名前と短い紹介** | **ほかのエージェントのプロフィール**（「誰の」を書く引数がありません） |
| 空にして消す | **どこで動いているか（エージェント）** —— `--as` か起動した場所で、**人が決めます** |

**エージェントを偽れないのが肝です。**名前だけなら「zumen」と名乗れてしまうので、
**画面は名乗りとエージェントの両方を出します**（`図面くん  zumen`）。

**名乗った名前は本人確認ではありません。**相手が呼び名を付けていれば、
**そちらが勝ちます**（**D46**）。

### 声で話せます（`voice_say`・#50）

**札（`voice.say`）と、人の印の両方がそろったときだけ鳴ります。**

```
voice_say {"text": "資料を共有しました。3 ページ目を見てください。"}
→ 声で流しました（23 文字）。同じ文を「（エージェントの声）」として会話にも流しました。
```

| 返り | 何が起きたか |
|---|---|
| 流しました | 会議の相手へ流し、この PC でも鳴らした。会話にも「（エージェントの声）…」の 1 行が出る |
| 入れていません | この PC の人が、そのルームで「この機械のエージェントの声を流す」を入れていない（**既定は切**）。**声で頼み直さず、文字で伝える** |
| 会議がありません | 映像と音を足した会議が無い・相手が居ない |
| 流せませんでした: … | 読み上げを作れない・鳴らせない（訳が付く） |

- **読み上げはこの PC の中で作ります**（macOS は `say`、Windows は System.Speech）。外の読み上げサービスへ文は送りません。それ以外の OS では「作れません」が返ります
- **`text` は 500 文字まで**です。長い文書の読み上げには使えません
- 人の印は**入れたルームだけ**に効き、**ルームを抜けると切に戻ります**
- 鳴らしている間は、マイクの代わりに声が送られます（終わればマイクへ戻ります）

### この機械の口は網に出ません

この機械の口は同じ機械の中だけの口です。
Unix ではソケットの権限を `0600` にしているので、**同じ機械の別のユーザーからも叩けません。**

### まだ無いもの

- **会話の履歴は残りません。**閉じれば消えます（`issues/010`）
- **受信箱は空です。**`inbox_*` は「無い」を返します（`issues/011` が決まるまで）
- **メールの返信はできません。**送る経路そのものがまだありません
