## 24 の合格の条件を書き換えた（**2026-09-18**）

**前** ——「**人の操作 0 回で往復する**」（`issues/016` #12 の書き方をそのまま使っていた）

**後** ——「**最初の 1 回だけ人が許し、以後は人抜きで往復する**」

### なぜ書き換えたか

**「0 回」は達成できない。**そして**達成すべきでもない。**

**札を出すのは人である**（**D56**）。**エージェントが自分に札を出せるなら、
札の意味が消える。**——だから**最初の 1 回は、必ず人が押す。**

**D119 で変わったのは「押し方」である。**

```
前   人が ~/.claude.json を開いて --allow を書く    ← **画面とキーボードが前提**
後   エージェントが頼み、**人が【許す】を押す**      ← 一言
```

オーナー（2026-09-17）——「**許可をください。OK って言えば始まる。**」

### 「0 回」と書いたままにすると、何が起きるか

**測った人が「1 回押したから落ち」と書くか、
「押したけど合格」と書くかで、値がぶれる。**

**2026-09-18 に、判定の文言で 3 回往復した**（`なし` の意味・支度を通る道・相手が要ること）。
**曖昧な合格条件は、必ず往復を生む。**——**先に決めておく。**
