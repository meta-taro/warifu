割符WARIFU

人と AI エージェントが、同じ 1 本の会話に入る。 中央のアカウントも、会話を預かるサーバーも作りません。

名前の由来は割符 —— 二つに割った札。片割れが合うことで、相手が確かにその相手だと分かります。

落とす

公式の配布物は GitHub Releases に置いています。macOS の画面（.dmg）は署名と公証済みです （CLI（warifu）も v0.1.5 から署名・公証済みです。落としてそのまま実行できます —— 実物で確かめました（隔離属性を付けた状態で warifu version が通ります。v0.1.4 までは止まったうえにファイルが消えていました）。単体の実行ファイルには公証の券を貼れないため、初回だけ網につながっている必要があります）。

macOS（Apple Silicon） 画面つき。.dmg を開いて Applications へ入れます。 .dmg を落とす
Windows（x64） 画面つき。-setup.exe で入れます（あなたのユーザーに入るので、 管理者権限は要りません）。 -setup.exe を落とす
Windows（.msi・管理者向け） 同じ中身です。機械ぜんぶに入れる形なので、管理者権限が要ります （無いと Error 1925 で止まります）。配布の仕組みで配る人向け。 .msi を落とす
CLI（画面なし） エージェントを繋ぐ・預かり所を立てる・画面のない機械から入る。macOS / Windows。 画面を上げても、このコマンドは上がりません。版を上げたときは、これも入れ直してください （warifu id が、画面と同じ身元かを自分で確かめて言います）。 実行ファイルを落とす
Windows は署名していません。「WindowsによってPCが保護されました」が出ます。 出どころを確かめてから［詳細情報］→［実行］を押してください。 心当たりが無いときは入れないでください。
Windows は、初めて開くときに通信の許可が要ります。 入れただけでは warifu-desktop.exe の規則が作られず、 環境によっては確認の窓も出ません。そのときは 文字は届くのに、映像だけ乗らないという形になります （コマンドは動くのに画面だけ繋がらない、いちばん分かりにくい形です）。 管理者の PowerShell で次の 2 行を打つと通ります。 
New-NetFirewallRule -DisplayName "warifu (in)" -Direction Inbound -Program "$env:LOCALAPPDATA\warifu\warifu-desktop.exe" -Action Allow
New-NetFirewallRule -DisplayName "warifu (out)" -Direction Outbound -Program "$env:LOCALAPPDATA\warifu\warifu-desktop.exe" -Action Allow
確認の窓が出るかどうかは Get-NetFirewallProfile | Select-Object Name, NotifyOnListen で分かります（False なら出ません）。

入れたら、最初の 3 手

相手も割符を入れている前提です。アカウント登録はありません。

  1. ルームキーを 1 本出して、相手に渡す 連絡帳 → ルーム →［このルームに人を呼ぶ］。リンク・QR・文字のどれでも渡せます （LINE でも、紙でも、口頭でも）。1 本につき 1 人です。
  2. 相手がリンクを押す 押すと「入りますか？」と尋ねます。勝手には入りません。
  3. つながったら呼び名を付ける 次からはルームキー無しで呼べます。付けなければ、次も初回と同じ渡し合いです。

AI エージェントを、その会話に入れる

MCP で繋ぎます。許す動作は人が書きます（既定は拒否）。 

claude mcp add warifu --scope user -- warifu mcp \
  --allow chat.send --allow chat.read --allow profile.write

書いたらエージェントを立ち上げ直します（口は起動時に読まれます）。 待たずに反応させるなら、常駐の口もあります。 

warifu agent --as souta --on ./run.sh

いま何ができるか

文字のやりとり 人と人、人とエージェント、エージェントとエージェント。1 本の会話に全員が入ります
ビデオ会議 2 人まで実測。同じ網の中でしか確かめていません（網を越えた実測は 0 件）
留守中の受け取り 相手が起動していない間、封のまま預かってもらえます（預かる側も読めません・任意）
予定 自分の予定を割符の中に置けます。外のカレンダーとは繋ぎません
4 言語 日本語 / English / 中文 / 한국어（メニューと右クリックも）

作らないもの

会話を預かるサーバー 立てません。届くのは、相手が起動しているか、預かり所を置いているときです
既読 送りません。出せるのは「相手の機械まで届いた」までで、読んだかどうかは誰にも分かりません
アカウント ありません。身元は端末の中の鍵です
3 人以上・網越え まだ実測していません。できると書けるのは、実物で見てからです
warifu — people and AI agents in one conversation, with no central account and no server holding the messages. Alpha: two-party video is measured on a single network only; anything across networks is unverified. The macOS app (.dmg) is signed and notarized; the CLI is not signed until the next release, and the Windows build is not signed. Source on GitHub.
